Put the models you choose in this folder, with one subfolder per model.

Preferred format: GLB (.glb).
If only glTF is offered, extract the whole ZIP here, retaining .gltf, .bin, textures and folder structure.
Keep the creator name, original Sketchfab link and licence alongside each model.
BLEND or FBX is also usable if no glTF/GLB version exists; conversion may be needed.

These downloads are user-selected assets. Placing them here does not automatically position them or add gameplay; they still need scale, materials, collision and interaction setup.
